# 爸妈用药记录 · 提示词

复制下面代码块，粘贴到「做个小工具」客户端的对话框。

## 完整提示词

```
做一个家庭用药打卡小工具，手机竖屏使用，子女分享给父母一起用。只做记录，不提供任何用药建议。

【角色】
- 子女：可增删改药品、查看全部历史、补记或更正记录。
- 老人：只能看今天要吃的药并点击"已服用"，可以撤销，看不到设置入口。

【功能】
1. 药品管理：药名、每天服用时段（早/中/晚/睡前，可多选）、每次用量（文字）、备注；可停用。
2. 今日清单：按时段分组，每个药一个"已服用"按钮，点击后显示打卡时间。
3. 状态：已服、未服、已过时段未记录（标红）。
4. 历史：按天、按周查看，统计漏服次数。
5. 子女首页显示今日已服和未服的数量。

【规则】
- 重复点击不重复记录；30 分钟内可撤销。
- 过了时段没打卡显示"未记录"，子女可补记并标注"补记"。
- 停用的药不再出现在今日清单，历史保留。
- 不做推送提醒、剂量计算、相互作用提示；不收集身份证、医保号、手机号。
- 页面底部固定显示"仅作记录，用药请遵医嘱"。

【界面】
- 老人端字要大、对比要强：正文不小于 22px，药名 28px，按钮高度不小于 64px、整行宽。
- 主色深绿 #2E7D32，背景白色，文字 #1A1A1A，警示红 #D32F2F，不要用浅灰小字。
- 今天没有药时显示"今天没有需要吃的药"。
```

## 二次修改提示词
