## 一句话定位

子女设置药品，老人点一下表示"已服用"，全家远程可看的用药记录工具。

## 角色与权限

- 子女：增删改药品和服药时段、查看历史、补记或更正记录。
- 老人：只看今日清单并打卡，可撤销，看不到设置入口。

## 核心功能

1. 药品管理：名称、每日时段（早/中/晚/睡前）、每次用量文字、备注。
2. 今日清单：按时段分组，一键"已服用"。
3. 状态显示：已服 / 未服 / 已过时段未服（标红）。
4. 历史：按天、按周查看，显示漏服次数。
5. 子女首页概览：今日已服和未服数量。
6. 停用药品：停用后不再出现在清单，历史保留。

## 约束边界

- 不做：推送或电话提醒、任何用药建议和剂量计算、药物相互作用提示、病历记录；不收集身份证、医保号、手机号。
- 页面固定显示免责说明："仅作记录，用药请遵医嘱"。
- 漏打卡：时段过后标"未记录"，子女可补记并标注"补记"。
- 重复点击不重复记录；误点可在 30 分钟内撤销。
- 假设药品不超过 15 种，仅支持一位老人（多位老人列为后续迭代）。

## 界面设计

- 老人端首页：大号日期和问候语；当前时段药品大卡片；整行的"已服用"大按钮。
- 子女端：概览卡、药品管理、历史。
- 风格：主色 #2E7D32，背景 #FFFFFF，文字 #1A1A1A，警示 #D32F2F；高对比，不使用浅灰小字。
- 字号：老人端正文不小于 22px，药名 28px，按钮高度不小于 64px、文字 24px。
- 空状态：「今天没有需要吃的药」；子女端「还没添加药品，点这里添加」。
- 关键交互：一键打卡后卡片变绿并显示打卡时间，同时出现"点错了，撤销"。

## 管理后台

药品增删改和停用；按日期查看服药记录；补记或更正；周/月漏服统计。

## 验收清单

- [ ] 老人端字号和按钮足够大，让父母实际试用一次。
- [ ] 打卡、撤销、防重复点击正常。
- [ ] 补记带有"补记"标识。
- [ ] 停用药品后历史保留。
- [ ] 免责说明常驻显示。
- [ ] 【需实测】老人身份是否真的看不到药品设置。
- [ ] 【需实测】过时段自动标红是否按时间生效。
