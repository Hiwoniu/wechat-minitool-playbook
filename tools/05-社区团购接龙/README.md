## 一句话定位

团长发布商品、邻居填数量、自动汇总的接龙工具。

## 角色与权限

- 团长：发布和编辑团购、设库存和截止时间、查看全部订单、标记已取货、查看汇总。
- 成员：浏览、下单；截止前可改或取消自己的订单；只能看自己的订单详情，以及公开的接龙列表（昵称加数量）。

## 核心功能

1. 发布团购：标题、多个商品（名称、规格、单价、库存可选）、截止时间、取货方式说明。
2. 下单：选商品数量、填称呼和楼栋门牌或取货备注。
3. 接龙列表：按顺序显示序号、昵称、所购商品。
4. 汇总：每个商品总数、每人应付金额、总金额。
5. 取货核销：团长逐单标记已取。
6. 结束或提前截止：之后不可下单。

## 约束边界

- 不做：在线支付、收款、物流、退款、优惠券；应付金额仅作展示，线下自行付款。
- 不收集手机号、身份证、详细住址，只收称呼和楼栋门牌或自提备注，且只有团长可见。
- 超库存：提交时校验，不足则提示剩余数量；库存为 0 显示"已抢完"。
- 重复提交：同一人再次下单视为修改原订单，不新增。
- 截止后订单锁定，只有团长可改。
- 假设单次团购不超过 20 个商品、300 单。

## 界面设计

- 页面：团购列表；团购详情（商品、接龙列表、底部"我要接龙"）；下单页；我的订单；团长汇总页。
- 详情页层级：截止倒计时和状态 > 商品与剩余库存 > 接龙列表。
- 风格：主色 #07C160，背景 #F6F6F6，价格 #FA5151；白底卡片，风格接近微信原生。
- 字号：正文 16px，价格 20px 加粗。
- 空状态：「还没人接龙，来做第一个吧」。
- 关键交互：数量加减步进器；提交后展示"我的接龙序号"。

## 管理后台

团购活动管理；订单列表（按商品或楼栋筛选）；商品汇总表；取货核销状态；历史团购数据。

## 验收清单

- [ ] 多商品下单与金额计算正确。
- [ ] 超库存拦截与"已抢完"正常。
- [ ] 重复下单变为修改而非新增。
- [ ] 截止后无法下单。
- [ ] 汇总数字与订单逐条相加一致。
- [ ] 【需实测】成员是否看不到他人的门牌信息（隐私关键项）。
- [ ] 【需实测】多人同时下单时库存是否会超卖。
- [ ] 【需实测】分享到群后，未使用过小工具的人能否直接打开。
