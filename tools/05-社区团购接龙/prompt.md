# 社区团购接龙 · 提示词

复制下面代码块，粘贴到「做个小工具」客户端的对话框。

## 完整提示词

```
做一个社区团购接龙小工具，手机竖屏使用，团长分享到群里，成员直接填。只做登记和统计，不做在线支付。

【角色】
- 团长：发布和编辑团购、设置库存和截止时间、查看全部订单、标记已取货、查看汇总。
- 成员：浏览商品并下单，截止前可修改或取消自己的订单；只能看到自己的订单详情，以及公开的接龙列表（序号、昵称、商品数量）。

【功能】
1. 发布团购：标题、多个商品（名称、规格、单价、库存可不填）、截止时间、取货说明。
2. 下单：用加减按钮选数量，填称呼和楼栋门牌或取货备注，提交后显示自己的接龙序号。
3. 接龙列表：按下单顺序显示。
4. 团长汇总：每个商品的总数量、每个人的应付金额、总金额。
5. 取货核销：团长逐单标记"已取货"。
6. 到截止时间或团长手动结束后，不能再下单。

【规则】
- 下单时校验库存，不够时提示剩余数量；库存为 0 显示"已抢完"。
- 同一个人再次下单视为修改原订单，不新增一条。
- 截止后订单锁定，只有团长能改。
- 称呼和门牌只有团长能看到。
- 不做支付、物流、退款、优惠券；不收集手机号和身份证；金额只做展示。

【界面】
- 页面：团购列表、团购详情、下单、我的订单、团长汇总。
- 详情页从上到下：截止倒计时、商品和剩余库存、接龙列表，底部固定"我要接龙"按钮。
- 主色 #07C160，背景 #F6F6F6，价格红 #FA5151，白底卡片；价格 20px 加粗。
- 没人下单时显示"还没人接龙，来做第一个吧"。
```
