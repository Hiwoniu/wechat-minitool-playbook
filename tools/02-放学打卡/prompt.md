# 放学打卡（家务积分作为二次迭代模块） · 提示词

复制下面代码块，粘贴到「做个小工具」客户端的对话框。

## 完整提示词

```
做一个孩子放学后的日程打卡小工具，手机竖屏使用，可邀请家人一起用。

【角色】
- 家长：可增删改事项、修改任意一天的打卡状态、查看全部历史。
- 孩子：只能给今天的事项打卡和撤销，可以看历史，不能改事项。

【功能】
1. 事项管理：增加、删除、修改、排序；周一到周五每天都是这些事项。
2. 今日打卡：每项有完成、部分完成、未完成三种状态，点一下卡片选择，5 秒内可撤销。
3. 历史记录：可按天、按周查看。
4. 周统计：本周完成率，每个事项的完成次数。

【规则】
- 周末不显示事项，显示"今天休息"。
- 当天没打卡的事项，第二天自动记为未完成。
- 删除事项后，历史记录保留并标注"已删除"。
- 重复点击同一事项是切换状态，不要生成多条记录。
- 不做推送提醒、支付、聊天、拍照；不收集真实姓名和手机号，只用昵称。

【界面】
- 页面：首页（今日进度条+事项列表）、历史、事项管理（仅家长可见）、统计。
- 主色浅紫 #B39DDB，背景 #F7F3FF；完成绿 #66BB6A，部分完成橙 #FFB74D，未完成灰 #BDBDBD。
- 圆角卡片，正文不小于 16px，按钮高度不小于 48px。
- 没有事项时显示"还没有事项，请家长先添加一个吧"。
```
