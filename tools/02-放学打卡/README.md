## 一句话定位

家长设置、孩子打卡、全家可回看的放学后日程工具。

## 角色与权限

- 家长（创建者及被邀请的家人）：增删改事项、修改任意一天的打卡状态、查看全部历史。
- 孩子：只能给当天事项打卡和撤销，可看历史，不能改事项。

## 核心功能（按优先级）

1. 事项管理：增、删、改、排序，周一到周五每天重复。
2. 当天打卡：每项三态（完成 / 部分完成 / 未完成）。
3. 历史回看：按天、按周切换。
4. 周统计：本周完成率、每项完成次数。
5. 身份区分：家长与孩子看到不同的操作入口。

## 约束边界

- 不做：推送提醒、奖励兑换、支付、聊天、拍照上传；不收集孩子真实姓名、学校、手机号，只用昵称。
- 周末默认不显示事项，显示休息提示。
- 删除事项后，历史记录保留并标注"已删除事项"。
- 当天未打卡的事项，次日自动记为"未完成"。
- 同一事项重复点击是切换状态，不产生多条记录。
- 假设事项不超过 20 项，成员不超过 6 人。

## 界面设计

- 页面：首页（今日日期、今日进度条、事项列表）；历史页（天/周切换、日历条、当日明细）；事项管理页（仅家长）；统计页。
- 首页层级：今日进度 > 事项列表 > 底部导航。
- 风格：浅紫主色 #B39DDB，背景 #F7F3FF，完成 #66BB6A，部分完成 #FFB74D，未完成 #BDBDBD；圆角卡片，童趣但不花哨。
- 字号：正文不小于 16px，事项名 18px，按钮高度不小于 48px。
- 空状态：「还没有事项，请家长先添加一个吧」。
- 关键交互：点卡片弹出三态选择，打卡后 5 秒内可撤销。

## 管理后台

事项的增删改；按日期查全部打卡记录并可更正；周/月完成率汇总；成员列表。

## 验收清单

- [ ] 三态打卡与撤销正常。
- [ ] 周一到周五重复、周末显示休息。
- [ ] 天/周历史数据正确。
- [ ] 删除事项后历史仍在。
- [ ] 【需实测】切换到孩子身份后，事项管理入口是否真的隐藏且无法修改。
- [ ] 【需实测】分享给家人后，对方打卡是否实时同步。
- [ ] 【需实测】次日自动记未完成是否生效（需跨天验证）。
- [ ] 【需实测】柱状图能否生成。
