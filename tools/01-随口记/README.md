## 一句话定位

聊天时对方随口说的事，切到小工具打一行字加回车就记下，自动按日期归好，还能两人共用一张清单。

## 角色与权限

- 私人清单：仅自己可见、可改。
- 共享清单：创建者邀请好友加入；双方都能记、完成、删除；每条显示谁记的、谁完成的。
- 共享清单的成员看不到对方的私人清单。

## 核心功能（按优先级）

1. 速记：顶部输入框常驻，一行文字加回车即保存，日期和分类都不必填。
2. 日期识别：用规则从文字里识别日期并归类，原文保留。
3. 五个视图：今天 / 明天 / 之后 / 未定日期 / 已完成。
4. 过期未完成的自动顶到"今天"并标红。
5. 可选"和谁"标签（如"小美"），可按人筛选。
6. 私人清单与共享清单切换。

## 约束边界

- 不做：读取微信聊天记录、从聊天自动抓待办、推送提醒、子任务、附件、重复任务。
- 不收集手机号、真实姓名；首次使用提示"内容保存在云端，请勿记录密码、证件号等敏感信息"。
- 日期规则：今天、今晚、明天、后天、周X / 星期X、下周X、X号、X月X日。
  - "周X"已过则取下周。
  - "X号"已过则取下月。
  - 识别不出的进"未定日期"。
  - 识别错了可点日期手动改。
- 空输入不保存；回车防重复提交；单条不超过 100 字。
- 共享成员退出后，其记过的条目保留，署名不变。
- 假设每张清单不超过 500 条，共享不超过 5 人。

## 界面设计

- 页面：首页（输入框、清单切换、视图标签、列表）；标签筛选；清单与成员设置。
- 首页层级：输入框 > 今天（过期的在最上）> 其他视图标签。
- 风格：极简白底；主色 #3B82F6，背景 #FFFFFF，分割线 #F0F0F0，过期红 #EF4444，已完成灰 #9CA3AF 加删除线。
- 字号：正文 17px，输入框高 52px 并自动聚焦。
- 空状态：「没有待办，听到什么就记一笔」。
- 关键交互：点左侧圆圈完成，5 秒内可撤销；左滑删除；保存后输入框清空并保持聚焦，可连续记；条目右侧显示识别出的日期小标签。

## 管理后台

全部条目的查看、搜索、批量改日期和删除；按标签或记录人统计；共享清单成员管理；已完成归档。

## 和前 5 个的区别

前 5 个是围绕固定场景的结构化记录，拼的是多人数据汇总。这个是无结构的个人高频入口，拼的是记录速度和"不离开微信"，共享只是加分项；它也是最适合做系列第一篇的入门款。
