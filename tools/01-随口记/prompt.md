# 聊天速记 Todo（暂名「随口记」） · 提示词

复制下面代码块，粘贴到「做个小工具」客户端的对话框。

## 完整提示词

```
做一个极简的速记待办小工具，手机竖屏使用。最重要的是记得快：打开就能打字，回车就保存。

【清单】
- 私人清单：只有我能看和改。
- 共享清单：可邀请好友加入，成员都能添加、完成、删除；每条显示谁记的、谁完成的。成员看不到别人的私人清单。

【功能】
1. 首页顶部常驻输入框，打开自动聚焦；输入一行文字按回车即保存，保存后清空并保持聚焦，可连续记。不要求填日期和分类。
2. 用规则（不要调用 AI）从文字中识别日期并归类，原文不改：今天、今晚、明天、后天、周一到周日/星期X、下周X、X号、X月X日。"周X"已过取下周，"X号"已过取下月；识别不出的放入"未定日期"。条目右侧显示日期小标签，点击可手动修改。
3. 视图标签：今天、明天、之后、未定日期、已完成。
4. 过期未完成的条目自动显示在"今天"最上方并标红。
5. 每条可选加一个"和谁"标签（如"小美"），可按标签筛选。
6. 点左侧圆圈完成，5 秒内可撤销；左滑删除。

【规则】
- 空内容不保存，回车防重复提交，单条最多 100 字。
- 成员退出共享清单后，他记的条目保留。
- 不读取聊天记录，不做推送提醒、子任务、附件。
- 不收集手机号和真实姓名；首次使用提示"内容保存在云端，请勿记录密码等敏感信息"。

【界面】
- 极简白底。主色 #3B82F6，过期红 #EF4444，已完成灰 #9CA3AF 加删除线，分割线 #F0F0F0。
- 正文 17px，输入框高度 52px。
- 没有待办时显示"没有待办，听到什么就记一笔"。
```
