# 搭子减脂榜 · 提示词

复制下面代码块，粘贴到「做个小工具」客户端的对话框。

## 完整提示词

```
做一个多人减脂打卡小工具，手机竖屏使用，分享给朋友一起用。只做记录和排行，不提供任何饮食或减重建议。

【角色】
- 发起人：创建挑战、设置起止日期、移除成员。
- 成员：记录自己的数据，能看自己的全部数据；看别人时只能看到减重百分比和打卡天数。
- 具体体重数值默认只有自己可见，成员可以自己选择是否公开。

【功能】
1. 创建挑战：名称、开始和结束日期。
2. 加入时填写初始体重和目标体重。
3. 每日记录：体重、今天是否运动、运动内容和时长、一句话备注。
4. 排行榜：按减重百分比从高到低排序，显示每人连续打卡天数。
5. 我的曲线：体重折线图和距离目标的进度。
6. 首页显示今天谁已经打卡。

【规则】
- 体重只能填 30–200 kg；和上次相差超过 3 kg 时弹窗让用户确认。
- 每人每天一条记录，重复提交覆盖当天；可以补记最近 3 天。
- 当天没记体重时，排行沿用最近一次记录。
- 成员退出后从榜单移除；挑战结束后只读，显示最终榜单。
- 不做 BMI、卡路里、推送提醒、押金奖金、拍照；不收集身高、年龄、真实姓名、手机号。

【界面】
- 页面：首页、记录、排行榜、我的曲线、小组设置。
- 首页从上到下：今日打卡卡片、我的减重进度、排行榜前三名。
- 主色 #00BFA5，背景 #F4FBFA，强调色 #FF6F61，第一名用金色 #FFC107；百分比数字 32px 加粗。
- 体重输入用数字键盘，默认带出上次的数值；打卡成功后显示我当前的排名。
- 今天没人打卡时显示"今天还没人打卡，抢个第一？"
```
