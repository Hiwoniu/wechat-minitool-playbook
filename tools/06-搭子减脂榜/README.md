## 一句话定位

几个朋友一起记体重和运动、按减重百分比排行的互相监督工具。

## 角色与权限

- 发起人：创建小组、设置起止日期、移除成员。
- 成员：记录自己的体重和运动；看自己的完整数据；看他人的减重百分比和打卡天数。
- 具体体重数值默认仅自己可见，可自行选择公开。

## 核心功能

1. 创建挑战：名称、起止日期。
2. 加入时填初始体重和目标体重。
3. 每日记录：体重、是否运动、运动内容和时长、一句话备注。
4. 排行榜：按减重百分比排序，显示连续打卡天数。
5. 个人曲线：体重折线图、距目标的进度。
6. 动态列表：今天谁打卡了。

## 约束边界

- 不做：饮食或减重建议、BMI 评判、卡路里计算、推送提醒、押金或奖金、拍照上传。
- 不收集身高、年龄、真实姓名、手机号。
- 异常值：体重限制在 30–200 kg；与上次记录相差超过 3 kg 时弹窗确认。
- 每天一条记录，重复提交覆盖当天；可补记最近 3 天，不可改更早的。
- 当天没有体重记录时，排行沿用最近一次。
- 成员退出后从榜单移除，其数据不再对他人可见。
- 挑战结束后只读，显示最终榜单。
- 假设每组不超过 20 人。

## 界面设计

- 页面：首页（今日打卡卡片、我的进度、排行榜前三）；记录页；排行榜；我的曲线；小组设置。
- 首页层级：今日是否已打卡 > 我的减重进度 > 排行榜。
- 风格：主色 #00BFA5，背景 #F4FBFA，强调色 #FF6F61，榜首金色 #FFC107；有活力、干净。
- 字号：正文 16px，百分比数字 32px 加粗。
- 空状态：「今天还没人打卡，抢个第一？」
- 关键交互：体重输入用数字键盘，默认带出上次数值；打卡成功后显示当前排名。

## 管理后台

小组和成员管理；每日打卡记录的查看与更正；打卡率统计；整体减重汇总。

## 验收清单

- [ ] 减重百分比计算正确：(初始 − 当前) ÷ 初始。
- [ ] 异常值拦截与确认弹窗正常。
- [ ] 同日重复提交为覆盖。
- [ ] 连续打卡天数在断签后归零。
- [ ] 折线图正常显示。
- [ ] 【需实测】切换到他人身份后，是否真的看不到具体体重（隐私关键项）。
- [ ] 【需实测】成员退出后，其数据是否从他人视角消失。
- [ ] 【需实测】挑战到期后是否自动变为只读。
