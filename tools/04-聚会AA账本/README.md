## 一句话定位

多人共同记账、自动算出"谁该给谁多少钱"的活动账本。

## 角色与权限

- 发起人：创建账本、管理成员、结束账本、删改任意账目。
- 成员：记一笔；只能改和删自己记的；所有人可看全部明细和结算结果。

## 核心功能

1. 创建账本：活动名称、成员（好友加入，或手动添加昵称）。
2. 记一笔：金额、付款人、参与分摊的人（默认全员）、用途、日期。
3. 明细列表：按时间倒序，可筛选付款人。
4. 结算：每人应付、已付、净额，以及转账次数最少的方案。
5. 标记"已结清"：逐条勾选，仅作记录。
6. 账本结束后只读。

## 约束边界

- 不做：支付、转账、收款码、多币种换算、小票识别；金额只记账不动钱；不收集手机号和银行卡。
- 中途退出的成员：标为"已退出"，不再参与新账目，历史账目照常结算。
- 中途加入的成员：只分摊加入后勾选了他的账目。
- 金额必须大于 0，保留两位小数；分不尽的尾差（几分钱）由付款人承担。
- 提交时防重复点击；删除需二次确认。
- 假设单个账本不超过 20 人、200 笔。

## 界面设计

- 页面：账本列表；账本首页（总支出、我的净额、最近账目、"记一笔"悬浮按钮）；记账页；结算页；成员页。
- 首页层级：我该付/该收的金额 > 总支出 > 明细。
- 风格：主色 #FF7043，背景 #FFF8F5，应收 #2E7D32，应付 #D32F2F；轻松清爽。
- 字号：正文 16px，金额数字 28px 加粗。
- 空状态：「还没有账目，记下第一笔吧」。
- 关键交互：参与人用头像或昵称多选，带全选；结算结果可一键复制为文字。

## 管理后台

全部账本和账目的查看与更正；成员管理；按人或按用途汇总支出；已结清状态查看。

## 验收清单

- [ ] 用 3 人 5 笔的小账手算一遍，核对结算结果。
- [ ] 尾差处理正确，各人金额合计等于总额。
- [ ] 部分人参与的账目分摊正确。
- [ ] 成员退出或中途加入后结算仍正确。
- [ ] 复制的结算文字可读。
- [ ] 【需实测】成员是否真的只能改自己的账目。
- [ ] 【需实测】分享到群后，多人同时记账是否冲突或丢数据。
- [ ] 【需实测】好友加入的实际流程，以及"手动添加昵称"的成员能否正常参与结算。
