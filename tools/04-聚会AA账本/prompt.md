# 聚会 AA 账本 · 提示词

复制下面代码块，粘贴到「做个小工具」客户端的对话框。

## 完整提示词

```
做一个多人 AA 记账小工具，手机竖屏使用，分享到群里大家一起记。只记账，不涉及任何支付和转账。

【角色】
- 发起人：创建账本、管理成员、结束账本、可删改任意账目。
- 成员：可以记一笔，只能修改和删除自己记的；所有人都能看全部明细和结算结果。

【功能】
1. 创建账本：填活动名称；成员可由好友加入，也可手动添加昵称。
2. 记一笔：金额、付款人、参与分摊的人（默认全选）、用途、日期。
3. 明细：按时间倒序，可按付款人筛选。
4. 结算：显示每人应付、已付、净额，并给出转账次数最少的"谁给谁多少钱"方案，可一键复制为文字。
5. 每条结算可标记"已结清"，仅作记录。
6. 发起人结束账本后，账本变为只读。

【规则】
- 金额必须大于 0，保留两位小数，除不尽的尾差由付款人承担。
- 成员退出后标记"已退出"，不参与新账目，历史账目照常结算。
- 中途加入的人只分摊勾选了他的账目。
- 提交按钮防重复点击；删除前二次确认。
- 不做支付、收款码、多币种、小票识别；不收集手机号和银行卡。

【界面】
- 页面：账本列表、账本首页、记一笔、结算、成员。
- 账本首页最上方显示"我应付/应收多少"，其次是总支出和最近账目，右下角悬浮"记一笔"按钮。
- 主色橙 #FF7043，背景 #FFF8F5，应收绿 #2E7D32，应付红 #D32F2F；金额 28px 加粗。
- 没有账目时显示"还没有账目，记下第一笔吧"。
```
