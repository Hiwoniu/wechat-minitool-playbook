# 为什么选这 6 个

选题标准只有一条：**这个需求放在微信里，是不是比放在别处更合适。**

至少满足一点：

- 使用的人本来就在微信里；
- 需要拉别人一起用；
- 对方不可能为这件事专门装一个 App。

| 小工具 | 给谁用 | 解决什么 | 为什么放在微信里 |
|---|---|---|---|
| [随口记](../tools/01-随口记/) | 我和对象、室友 | 聊天里答应的事转头就忘 | 聊天就在微信，不想切 App |
| [放学打卡](../tools/02-放学打卡/) | 家长和孩子 | 每天口头催作业，没有记录 | 爸妈、老人能共用一份 |
| [爸妈用药记录](../tools/03-爸妈用药记录/) | 子女和父母 | 不在身边，不知道药吃没吃 | 父母不用学新 App |
| [聚会 AA 账本](../tools/04-聚会AA账本/) | 一起出游的朋友 | 玩完算账麻烦又尴尬 | 丢进群里，所有人一起记 |
| [社区团购接龙](../tools/05-社区团购接龙/) | 团长和邻居 | 群接龙改来改去，统计靠手算 | 邻居点开就能填 |
| [搭子减脂榜](../tools/06-搭子减脂榜/) | 几个减肥的朋友 | 一个人坚持不下去 | 互相看得见才有监督 |

这 6 个都是小需求，用的人可能只有两三个，最多一个群。过去没人会为它们专门开发一个应用。

## 更多可做的方向

| 场景 | 点子 |
|---|---|
| 家庭 | 零花钱小银行、家务积分榜、宠物喂养交接 |
| 小商家 | 熟客预约本、会员储值记录 |
| 自由职业 | 接单进度板、收款对账本 |
| 教师 / 培训 | 课时消耗表、班级阅读打卡 |
| 社群 / 团队 | 活动报名表、值班表、21 天打卡 |
| 活动 | 婚礼宾客回执 |
| 租房 | 合租公摊账本、房东收租台账 |
