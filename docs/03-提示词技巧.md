# 写给「做个小工具」的提示词技巧

1. **按「角色 / 功能 / 规则 / 界面」分块写。** 它会先做一次方案确认，分块写的需求更容易逐条核对。
2. **写清「不做什么」和边界情况。** 重复提交、空状态、超限这类规则第一次就写进去，比事后一条条补省时间。
3. **界面给具体值。** 色值、字号、按钮高度直接写数字，别写「好看一点」「适合老人」。
4. **改动分两种方式。** 功能和整体风格在对话框里说，一次只提一件事；单个文字或按钮用元素选择器点选后再说。改坏就回退，别在错误版本上叠加。
5. **先验收再生成后台。** 在模拟器里切换各个身份走完整流程，再推到手机真机试用；前台确认无误后再生成后台。
6. **不确定支不支持，就让它直说。** 比如提醒、读取剪贴板，在提示词里加一句「如果做不到请直接告诉我」，比它悄悄做个假的强。
