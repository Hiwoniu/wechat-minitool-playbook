# 用「做个小工具」做一个应用：完整流程

「做个小工具」是微信内测中的桌面客户端（Beta，macOS / Windows），用一句话描述需求，生成一个能在微信「小微」里直接用的小工具。

小工具可以理解成简版小程序：不用注册、备案、认证，也不用提交审核，做完就能用，还能分享给朋友一起用。

## 9 步

| # | 步骤 | 要点 |
|---|---|---|
| 1 | 下载并登录 | 安装客户端，用微信登录 |
| 2 | 说出需求 | 界面只有一个对话框，可加附件、选权限模式；没有模型选项，用的是微信自研大模型 |
| 3 | 方案确认 | 它会先列出理解到的功能让你确认，重点看「使用范围」是否为可邀请朋友一起用 |
| 4 | 云端开发 | 开发在云端完成，本地不用装环境 |
| 5 | 模拟器预览 | 右侧手机模拟器可直接点着用，还能切换身份看别人打开时的样子 |
| 6 | 推送到微信 | 编译并预览，推送到电脑和手机微信的小微里，真机可用 |
| 7 | 修改 | 对话框里直接说；或用元素选择器点中某个文字、按钮再说怎么改 |
| 8 | 版本回退 | 改坏了退回之前的版本 |
| 9 | 生成管理后台 | 右上角入口，为小工具再生成一个后台，用来查看和管理数据 |

## 注意

- **权限模式**：「完全访问权限」开启后 AI 可以不经批准操作电脑上的多项权限，做小工具用不到，不建议开。
- **数据在云端**：密码、证件号、病历、银行卡别往里写。
- **内测阶段**：功能和入口随时可能变，以你实际看到的为准。
